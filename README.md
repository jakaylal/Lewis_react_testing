# Lewis_react_testing
The testing strategy I used for my application was to begin identifying what functions were created and needed to be validated that they work. I did this by listing the functions needed for the application, as well as noting what they needed to do and what the input and output needed to be. More importantly, I used unit testing to accurately test the lines of code to make sure that it aligned with the expected output. What I learned the most is that testing is not as straightforward as it seems, but it is vital to ensure that you are not only testing that the code works, but more importantly, you are testing that the code reaches the expected output. For example, if you test that a function is working but not the expected output, then testing does not help as much with solving problems or identifying bugs.
